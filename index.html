      ABOUT THIS DEMO

      How the local app works

      The Python app saves events, dependencies, waiting requests, and undo history in scheduler_data.json in the project folder. Export creates a JSON backup of events and dependency links; queue requests and undo history stay in the local data file.

      The browser displays the interface and sends your actions to the Python app running on this computer. Python handles event validation, room-conflict checks, searching, sorting, priority ranking, queue processing, undo, and graph traversal.

      This is a single-computer classroom demo, not a shared multi-user or hard real-time system. Events that touch at an endpoint (one ends at 10:00 and another starts at 10:00) do not conflict.
